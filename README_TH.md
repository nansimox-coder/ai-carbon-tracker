# Carbonly — AI Carbon Tracker (Modern Prototype)

เว็บแอปภาษาไทยสำหรับบันทึกกิจกรรมด้านการเดินทาง ไฟฟ้า และอาหาร พร้อมสรุปผลเป็น kg CO₂e, กราฟ Dashboard, เป้าหมายรายสัปดาห์ และคำแนะนำตามหมวดที่มีค่าประมาณสูงสุด

## สิ่งที่มีในเวอร์ชันนี้
- Responsive layout ของ Streamlit สำหรับหน้าจอคอมพิวเตอร์และมือถือ
- บันทึกกิจกรรมและคำนวณค่าประมาณ
- Dashboard, กราฟแนวโน้ม และสัดส่วนแต่ละหมวด
- ตั้งเป้าหมายรายสัปดาห์
- คำแนะนำแบบ rule-based
- ประวัติและดาวน์โหลด CSV

## สำคัญ: ความสามารถ AI และข้อมูล
เวอร์ชันนี้เป็น functional prototype ที่ใช้สูตรคำนวณและกฎเลือกคำแนะนำ ยังไม่ได้เชื่อมต่อ LLM หรือ Predictive AI จริง ค่าปัจจัยการปล่อยในโค้ดเป็นค่าตัวอย่างเพื่อการสาธิต ไม่ใช่ค่าอ้างอิงทางการ ต้องตรวจสอบ/แทนที่ด้วย emission factors ที่เหมาะกับประเทศไทย ปีที่ใช้ และขอบเขตกิจกรรม พร้อมระบุแหล่งอ้างอิงก่อนนำเสนอเป็นผลจริง

## วิธีเผยแพร่เว็บไซต์โดยไม่เขียนโค้ด
1. ดาวน์โหลด ZIP และแตกไฟล์
2. สร้างบัญชี GitHub ที่ https://github.com/
3. สร้าง repository ใหม่ชื่อ `ai-carbon-tracker` เลือก Public
4. อัปโหลดไฟล์ `app.py`, `requirements.txt`, `.gitignore` และโฟลเดอร์ `.streamlit` (ภายในมี `config.toml`) ไปยัง repository
   - `README_TH.md` อัปโหลดเพิ่มได้
   - หาก GitHub ไม่แสดงไฟล์ที่ขึ้นต้นด้วยจุด ให้สร้าง/อัปโหลด `.gitignore` และโฟลเดอร์ `.streamlit` ตามปกติ หรือใช้ GitHub web editor สร้างไฟล์
5. เปิด https://share.streamlit.io/ แล้วเลือก Continue with GitHub
6. กด Create app แล้วเลือก repository `ชื่อผู้ใช้/ai-carbon-tracker`
7. Branch เลือก `main`; Main file path ใส่ `app.py`
8. กด Deploy และรอจนระบบสร้าง URL `.streamlit.app`

## ทดลองในคอมพิวเตอร์ (ไม่จำเป็นสำหรับการ Deploy)
ต้องติดตั้ง Python 3.10+ แล้วเปิด Command Prompt ในโฟลเดอร์โปรเจกต์:
```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

## ข้อจำกัดที่ควรรู้
- ข้อมูลบันทึกใน CSV ภายในพื้นที่รันแอป เหมาะกับ demo เท่านั้น ไม่ใช่ฐานข้อมูลถาวร
- บน cloud ข้อมูลไฟล์อาจหายเมื่อแอป restart, rebuild หรือย้ายเครื่อง
- ไม่มีระบบบัญชีผู้ใช้หรือแยกข้อมูลรายคน
- ไม่ควรกรอกข้อมูลส่วนบุคคลหรือข้อมูลอ่อนไหว
- แนะนำให้เพิ่มฐานข้อมูลถาวร เช่น Supabase และระบบล็อกอินก่อนเปิดใช้จริงกับผู้ใช้หลายคน
- การเปิดแอปจากมือถือและคอมพิวเตอร์ทำได้ผ่าน URL เดียวกัน โดย Streamlit ปรับ layout ตามหน้าจอ
